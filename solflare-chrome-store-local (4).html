Add Solflare Wallet to Chrome

Install the extension manually with these steps:

  1. Download the extension package.
    Download extension
  2. Extract the downloaded file (right-click → Extract / Unzip).
  3. Open the Extensions page. You can do this in two ways:
    • Type chrome://extensions into the address bar (or into the search bar above) and press Enter.
    • Or go via the menu:
      At the top right, select More Extensions Manage extensions.
  4. At the top right of the Extensions page, turn on Developer mode.
  5. Click Load unpacked and select the extracted folder,
    or simply drag and drop the extracted folder onto the page.
